# 演示脚本

供 W8 录像使用。目标时长约 5 分钟。代码提交 `04c22914a86f9cd3d1d6cf9050b4e2e16055627e`。候选程序 `.dart_tool/w06-d5/candidate/desktop.exe` 的 SHA-256 是 `159a7f0294655b9b55d6ae781c56827b3fa9045283feeccf60e42cfc12dbce27`。片头先念这两项。若录像时提交已经前移，改念当时的 `HEAD` 和该次构建的哈希，不要继续用这一组。

下面的画面若还没有候选程序的原生窗口录像，就用已归档截图，并在旁白里说明它是哪一次运行。无界面探针通过，不等于窗口操作已经通过。

## 1. 离线与本机目录（约 40 秒）

| 项 | 内容 |
|---|---|
| 画面 | 资源根目录和空的数据目录。不打开浏览器，不出现模型下载 |
| 操作 | 指出 `AMR_RUNTIME_ROOT` 或可执行文件旁的 `runtime/`，以及 `AMR_DATA_DIR` |
| 旁白 | 索引建在本机。生产路径使用 ONNX Runtime、Apache Tika 和系统 SQLite。公开安装包不附带 MobileCLIP 权重 |
| 证据 | [技术文档](技术文档.md) 第 3 节，[候选清单](../week6/logs/D5_candidate_manifest.json) |
| 不能展示 | 三平台安装器。macOS 和 Linux 的生产推理尚未验证 |

## 2. 建立索引（约 70 秒）

| 项 | 内容 |
|---|---|
| 画面 | 文件库。一个小样本目录完成索引，并有一份失败文件的说明 |
| 操作 | “选择目录”或填绝对路径，然后“建立 / 增量更新索引” |
| 旁白 | 未改动的文件会复用。取消停在安全点，已经写入的部分保留。源文件不被改写 |
| 证据 | 开发模式画面 [M04-index.png](../week6/screenshots/M04-index.png)。无界面的取消与续建见 [M05.txt](../week6/logs/M05.txt) 和 [M05-cancelled.png](../week6/screenshots/M05-cancelled.png) |
| 不能展示 | 把 M04 说成候选程序的原生窗口验收。2026-11-15 重跑无界面冒烟没有产生新的 JSON |

## 3. 查询、出处和打开原文件（约 70 秒）

| 项 | 内容 |
|---|---|
| 画面 | 搜索“离线检索”一类已出现在样本里的句子。结果页有文件名、片段、页码或“无物理页码”，然后系统打开原文件 |
| 操作 | “开始搜索”，再按“打开原文件” |
| 旁白 | 最多显示前 20 条。排序分值不是正确概率。查看器不一定能跳到该页或该段 |
| 证据 | [M04-results.png](../week6/screenshots/M04-results.png)。打开失败和缺文件的界面见 [M05-missing-source.png](../week6/screenshots/M05-missing-source.png) |
| 不能展示 | 用中文问句保证找出厨房披萨那张图。该限制仍记在 W4，本脚本不把它演示成已修复 |

## 4. 键盘或读屏，以及显示（约 60 秒）

| 项 | 内容 |
|---|---|
| 画面 | 只用键盘完成一次搜索。若机器上有 NVDA，再听一条结果的名称。设置页展示高对比或 150% 字号 |
| 操作 | Tab 到搜索，Ctrl+L 聚焦，Enter 提交。设置里切换已经在 W5 测过的一项 |
| 旁白 | Windows 的键盘和 NVDA 记录来自 W5，版本 NVDA 2026.2.0.57664。VoiceOver、macOS 和 Linux 还没有实机记录 |
| 证据 | [NVDA 实机记录](../week5/logs/screen_reader_nvda_session.md)，字号截图在 `reports/week5/screenshots/` |
| 不能展示 | 独立试用者。人数仍是 0。不要说试用者没有发现问题 |

## 5. 技术路径与界限（约 40 秒）

| 项 | 内容 |
|---|---|
| 画面 | 架构图或一张只含六层名称的简图。停在检索结果，不打开训练或下载页面 |
| 操作 | 不需要新的点击 |
| 旁白 | 文件先解析，文本和图像用 ONNX 嵌入，向量放在 SQLite，结果由关键词、文本向量和图像向量融合。PDF 仍用 Tika，没有换 PDFium。10k 规模的普通热查询 p95 是 463.18 毫秒，高于 200 毫秒的预算，这次录像不把它说成已经达标 |
| 证据 | [架构文档](../../docs/architecture/system-architecture.md)，[W6 D5](../week6/W06_D5_checkpoint.md) |
| 不能展示 | 融合权重、切块版本或图像模型在录像前被临时改过。脚本使用提交里的现成行为 |
