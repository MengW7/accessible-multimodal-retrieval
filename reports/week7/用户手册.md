# 用户手册

文档依据的代码提交是 `04c22914a86f9cd3d1d6cf9050b4e2e16055627e`。编写日期 2026-11-15。本文按这个提交里的界面用词编写。Windows 键盘、NVDA 和显示设置的实机记录仍是 W5 的记录，不是本周新测的。

当前没有面向 Windows、macOS、Linux 的安装器。macOS、Linux 和生产模式下的 VoiceOver 未验证。

## 1. 开始之前

这个程序在你的电脑上为本地文件建立索引，再用文字查询、筛选和打开原文件。可以处理的类型是 TXT、Markdown、PDF、DOCX、JPG 和 PNG。

Windows x64 生产运行需要本机已经放好的资源目录，里面有 ONNX Runtime、两套模型、分词器和 Apache Tika，以及 PATH 里的 Java。资源怎么准备见 [技术文档](技术文档.md) 第 3 节。MobileCLIP 权重不在公开下载包里，需要按研究许可自己准备。

程序会把索引放到一个数据目录。你可以用环境变量 `AMR_DATA_DIR` 指定一个空目录的绝对路径。不指定时，Windows 使用 `%LOCALAPPDATA%\AccessibleMultimodalRetrieval`。请把演示数据和评测库分开。源文件留在你选择的文件夹里，索引不会把它们改掉。

启动后若设置页把某项标为“阻塞”，先让维护者补上写出的那个文件，再按“重新检查依赖”。依赖未就绪时不要反复建库。

## 2. 四个功能区

宽窗口左侧是“文件库”“搜索”“结果”“设置”。窗口变窄时导航会改换布局。内容超出窗口时向下滚动，键盘继续按 Tab。

| 功能区 | 你可以做什么 |
|---|---|
| 文件库 | 选择目录、建立或增量更新索引、看每个文件的结果、取消、清除全部索引 |
| 搜索 | 输入查询，并按类型、相对路径和修改日期筛选 |
| 结果 | 看本次条件、片段和出处，请求系统打开原文件 |
| 设置 | 主题、高对比、文字大小，以及本地运行依赖 |

## 3. 建立文件库

1. 准备一个你有权读取的文件夹。试用时用单独的样本目录。
2. 打开“文件库”。按“选择目录”，在系统窗口里选定文件夹。也可以在“目录的绝对路径”填完整路径。
3. 按“建立 / 增量更新索引”，等待阶段和计数结束。模型第一次加载会更久。
4. 看本次文件状态。部分失败表示只有这些文件没有入库，其他文件可以已经写入。

同一内容可能共用一条索引，所以文件数和索引文档数可以不同。

文件有改动时，对同一目录再按一次“建立 / 增量更新索引”。未改动的内容会复用。要停止时按“取消索引任务”，等到安全点。已经写入的部分会留下。关掉窗口不等于按了取消。

文件改名或删除后，旧索引可能还在。增量不会保证清掉这些旧记录。需要整库重来时，用第 7 节的清除，再重新添加目录。

## 4. 搜索与筛选

1. 打开“搜索”，或在 Windows 和 Linux 上按 Ctrl+L。macOS 上对应的是 Command+L，该快捷键没有在 macOS 上验证。
2. 在“搜索本地内容”输入非空的关键词或一句话。
3. 第一次先保持“所有类型”，路径和日期留空，按 Enter 或“开始搜索”。
4. 到结果页核对“本次查询”。要改条件时按“修改搜索条件”，改完必须再提交。

| 筛选项 | 规则 |
|---|---|
| 文件类型 | 所有类型、TXT、Markdown、PDF、DOCX、图片（JPG / PNG） |
| 相对目录或文件路径 | 相对导入目录，例如 `notes` 或 `notes/file.pdf`。这里不填盘符 |
| 修改时间晚于日期 | `YYYY-MM-DD`，表示晚于该日本地时间零点，不含这一刻。不存在的日期会被拒绝 |
| 清除筛选 | 只清空表单。当前结果不会自动换成无筛选结果，需要再搜一次 |

每次最多显示前 20 条。文件库还在建索引时，搜索会提示等待或先取消建库。搜索过程中可以按“取消当前搜索”。

## 5. 阅读结果与打开原文件

结果按相关性排列。界面写明排序分值不代表正确概率。

- 文本结果显示片段。片段可以带相邻上下文。字符偏移是命中块的 UTF-16 范围，含首不含尾。
- 有页码的结果显示“出处：第 N 页”。没有物理页码的结果会直接说明无页码。
- 图片结果显示文件名和元数据，并说明没有生成图像内容描述。
- 按“打开原文件”。成功时提示已经请求系统打开，并说明查看器可能无法跳到该页或该段。

源文件被移走或删掉时，会提示文件不存在或不可访问。系统没有接上打开功能时，提示复制来源路径后手动打开。索引更新或清除之后，旧的结果页会失效，需要重新查询。

从系统查看器回到本程序时，用系统自己的窗口切换。焦点落在哪个控件上，还没有对所有查看器做完记录。

## 6. 键盘、读屏和显示

| 按键 | 作用 |
|---|---|
| Tab / Shift+Tab | 在控件间移动 |
| Enter | 在搜索框提交；在按钮上执行 |
| Space | 激活按钮或开关。在搜索文字里它是空格，不是提交 |
| 方向键、Enter | 在打开的下拉项里移动并确认 |
| Esc | 关闭当前程序弹窗。系统窗口按系统自己的规则 |
| Ctrl+L | Windows 和 Linux 上进入搜索并聚焦输入框。有弹窗时先关上弹窗 |

清空确认框打开时，焦点在“保留索引”上，Tab 在框内循环。Esc 或“保留索引”会关闭框并回到触发它的控件。这是界面上的说明和实现。W5 对纯键盘主流程有记录，见 [验收矩阵](../week5/E_验收矩阵.md)。

Windows 上的 NVDA 记录是 [NVDA 实机记录](../week5/logs/screen_reader_nvda_session.md)，版本为 NVDA 2026.2.0.57664。先按你平时的方式打开 NVDA，再用 Tab 和 Enter 完成导入、搜索和打开。加载、完成和错误有语义标签。进度不会逐个文件朗读。本周没有再开一次 NVDA。

VoiceOver、macOS 和 Linux 各有一行：未验证。本文不写未测过的读屏快捷键。

显示在“设置”里：

| 设置 | 选项 |
|---|---|
| 明暗主题 | 跟随系统、浅色、深色 |
| 高对比模式 | 可手动打开。系统要求高对比时也会自动启用 |
| 文字大小 | 跟随系统、100%、150%、200% |
| 恢复默认显示设置 | 恢复上述三项的默认值，不清除索引 |

选定 100%、150% 或 200% 时，不再乘一次系统文字比例。字号变大后若按钮在窗口外，向下滚动或继续 Tab。设置保存在当前数据目录，同一数据目录再次启动会恢复。W5 在 100%、150%、200% 下留有截图，见 `reports/week5/screenshots/`。那些图是当时的开发运行画面。

课程 PDF 点名的 Accessibility Scanner 面向 Android，WAVE 面向网页。本程序是桌面界面，这两项工具没有对它出报告。替代记录在 [无障碍合规验证报告](../week5/无障碍合规验证报告.md)。

## 7. 清除索引与退出

“清除全部索引”清除的是当前数据目录里的全部索引和已保存目录，不是输入框里的某一个文件夹。源文件保留。清除后要重新添加目录。

1. 先看设置页或确认框里的索引位置。
2. 按“清除全部索引”，读完说明。
3. 不想清除时按 Esc 或“保留索引”。
4. 确定要清除整个索引时，才按“确认清除索引”。

关闭窗口时，若后台还在收尾，等待当前安全点。不要对同一个数据目录同时开两个正在写入的实例。后一个写入会提示另一个实例正在修改此文件库。

## 8. 常见提示

| 提示 | 可以怎么做 |
|---|---|
| 依赖项为阻塞，并给出缺少的文件 | 把文件放到提示的路径，或让维护者设置资源根，然后“重新检查依赖” |
| 索引库为空 | 先添加目录并完成建库 |
| 当前条件下没有检索结果 | 放宽类型、路径或日期后再提交。这不表示资料里一定没有答案 |
| 日期或路径不被接受 | 日期用真实的 `YYYY-MM-DD`，路径用相对路径 |
| 源文件不存在、不可访问或不是文件 | 把文件放回原来的绝对路径，或更新索引 |
| 系统未能打开文件 | 检查权限和默认查看器，或复用来源路径自行打开 |
| 另一个实例正在修改此文件库 | 等对方结束、取消或退出后再试 |
