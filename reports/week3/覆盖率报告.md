# 覆盖率报告

## 命令

在 `packages/core_embedding` 下执行。读取 `tokenizer.json`、fp32 ONNX、`datasets/samples` 和 COCO 图片的测试带 `integration` 标签，不计入这次覆盖率。

```powershell
dart test --coverage=coverage --exclude-tags integration
dart run coverage:format_coverage --lcov --in=coverage --out=coverage/lcov.info --report-on=lib --package=.
```

统计 `reports/week3/coverage/lcov.info`：

```text
lines hit 1250 / 1458 = 85.73%
```

同一数字写在 `reports/week3/logs/text_coverage_c.txt`。本包设了两条门槛：中途一条按 70% 卡，交付一条按 85.00% 卡（G3 / D5）。85.73% 一次跨过两条。根 `.gitignore` 的 `coverage/` 会忽略任意同名目录，`reports/week3/coverage/` 有一条否定规则，所以这份副本可以被普通 `git add` 收进库。

2026-10-16 按同一条命令重跑了一次。`dart test --exclude-tags integration` 的结束行是 `00:01 +93: All tests passed!`。带 `--coverage` 的那次结束行是 `00:11 +93: All tests passed!`。`reports/week3/coverage/lcov.info` 仍是 1250/1458 = 85.73%。汇总在 `reports/week3/logs/coverage.txt`。`bin/embed_probe.dart` 不在 `lib/` 里，不进入这个百分比。
