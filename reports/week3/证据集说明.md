# 证据集说明

W3 只建集、冻结口径，不出检索分数。Hit@5 和 MRR@10 留到 W4，那时才有索引和排序。本文件对应 `reports/week3/evidence_set.jsonl`。

## 1. 范围

25 条，全部来自仓库里已经能导入的文件。问题不写文件名。

| 来源 | 条数 | 相关文件 |
|---|---:|---|
| `datasets/samples/sample.pdf` 与 `sample.docx` 的正文 | 12 | 两份都算相关。PDF 用 Tika `-x` 的页文本，偏移按页 |
| `sample.docx` 的 `docProps/core.xml` | 3 | 只算这份 docx。创建者、空标题、创建时间不在正文里 |
| `datasets/coco/val_sample` 的 8 张图 | 8 | 每条只对应 captions.jsonl 里的那一张 |
| `datasets/samples/sample.png` | 2 | 人读图面文字。图像解析器不做 OCR，正文为空 |

dev 15 条：`ev-01`–`ev-15`。holdout 10 条：`ev-16`–`ev-25`。

## 2. 字段

每行一个 JSON 对象。

| 字段 | 含义 |
|---|---|
| `id` | 稳定编号 `ev-01`–`ev-25`。不是 chunkId |
| `question` | 问句。不含文件名 |
| `relevantDocumentId` | 主相关文件，仓库相对路径 |
| `relevantDocumentIds` | 全部相关文件。正文题同时包含 pdf 和 docx，因为两份正文都有同一句 |
| `evidenceLocation` | 主证据位置，和 `evidenceLocations` 的第一项相同 |
| `evidenceLocations` | 证据位置列表。标在原文或文件上，不标 chunkId |
| `evidenceText` | 证据原文。正文题是页文本里的连续子串。`ev-10` 的标题证据是空字符串 |
| `referenceAnswer` | 给人看的简答 |
| `answerable` | 这 25 条都是 true。没有故意放进无答案题 |
| `split` | `dev` 或 `holdout` |
| `crossPage` | 证据是否同时落在 PDF 的两页上 |
| `modality` | `text`、`metadata` 或 `image` |

正文位置的格式：

```text
datasets/samples/sample.pdf#page=1;textUnit=utf16CodeUnit;start=135;end=156
```

`start` 含首，`end` 不含尾，单位是 UTF-16 code unit，和 `String.substring` 一致。DOCX 没有物理页，`CascadeTextChunker` 也不会把解析器里的 `pageNumber: 1` 当成真实页码，所以 docx 位置写成 `page=null`，偏移相对抽出的整篇正文。

图像题的位置就是图片相对路径。`evidenceText` 是 `captions.jsonl` 里的原句，保留行首行尾空格。`ev-15` 和 `ev-25` 多一个 `parserExtractedText: false`，表示那两句是图面上能看见的字，不是解析结果。

## 4. 跨页

`crossPage: true` 的是 `ev-08`、`ev-16`、`ev-17`。这三题的证据句在 PDF 第 1 页和第 2 页都有完整落点，位置都写进了 `evidenceLocations`。

`sample.pdf` 抽出的两页是同一篇说明的重复排版，不是一句从第 1 页末尾续到第 2 页。因此这三题记录的是「同一证据出现在两页」，不是「半句在下一页」。W4 的邻域扩展在这批题上没有跨页断句可以测。通过标准仍定在 W4，这里不打分。

## 5. 不在本集里的事

- 不把 chunkId 当标签。切块参数一变，块的边界就会变。
- 不收录 RVL-CDIP。那 16 张图没有标题。
- 不把 `sample.png` 算进正文题的相关文件。图上的字没有进解析文本。
- 生成式答案是否引用了证据，不在本集的完成标准里。
