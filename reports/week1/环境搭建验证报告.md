## 证据说明

### Flutter

`flutter doctor` 确认 SDK、Windows 版本、Chrome 和 Visual Studio 桌面工具链可用，并且可以看到 3 个设备。`flutter test` 在 `apps/desktop` 中通过。该测试仍是 Flutter 模板的计数器冒烟测试，还不是业务功能测试。

### Git

`reports/week1/env_git.txt` 记录：

```text
git version 2.38.0.windows.1
```

### Java

`java -version` 输出：

```text
java version "17.0.4" 2022-07-19 LTS
Java(TM) SE Runtime Environment (build 17.0.4+11-LTS-179)
Java HotSpot(TM) 64-Bit Server VM (build 17.0.4+11-LTS-179, mixed mode, sharing)
```

### Python、Chroma 与 TFLite

依赖安装在 虚拟环境`engine/.venv`中：

```text
Python 3.13.2
chromadb 1.5.9
tensorflow 2.21.0
```

运行一下命令：

```text

```

结果保存在`week1_tika_pdf.txt` 。
