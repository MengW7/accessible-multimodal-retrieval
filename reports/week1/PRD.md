# 项目需求文档（PRD）
## Offline Accessible Multimodal Local Content Retrieval System
- 日期：2026-09-24
- 周期：8周

## 1.目标与范围
### 1.1目标
做一个完全离线、开源、能在Windows / macOS / Linux 上运行的桌面工具：把电脑里的PDF、文档和图片建成本地索引，用自然语言或关键词搜回来，并保证视障用户也能独立完成搜索。
### 1.2要解决的问题
- 本地文件数量繁多，格式多样，需要更好的方式来查找本地文件
- 保证本地数据安全，不要上传文件到云端，所有的检索操作全部再本地完成
- 为包括视障人群在内的数十亿人提供更好的帮助，实现无障碍标准
### 1.3需要完成的工作
- Linux、Windows以及MacOS三个平台上可运行的应用
- GitHub仓库，包括代码、文档以及开源许可
- 技术文档、用户手册
- 5 分钟演示视频

## 2.功能性需求
| 功能 | 具体要求 |
| :--- | :--- |
| 导入本地文件 | 选择文件夹，扫描 TXT / PDF / DOCX / JPG / PNG |
| 解析 | 文本文件抽正文；PDF 抽文本层并记下页码；图片可送入图像模型 |
| 过滤 | 按类型/ 文件夹/ 时间过滤 |
| 进度 | 索引进度条和取消 |
| 离线嵌入 | 文本用 BERT（TFLite），图片用 MobileCLIP，本地模型，不需要联网下载 |
| 本地检索 | Chroma DB 存向量；支持关键词 + 语义相似度混合排序 |
| 统一接口 | 一句话既能搜到文档片段，也能搜到相关图片 |
| 界面 | Flutter：文件库、搜索框、结果列表、设置 |
| 打开结果 | 用系统默认程序打开原文件 |
| 无障碍 | 键盘能走完「搜索 → 看结果 → 打开」；控件有名字；支持高对比和字号放大 |

## 3.非功能性需求
| 类别 | 要求（按实习项目可达到的程度） |
| :--- | :--- |
| 离线 | 断网也能导入、搜索、打开本地文件；默认不外传任何用户数据 |
| 平台 | Flutter 桌面；保证在 Window、Linux、MacOS上能运行 |
| 性能 | 已建库后，一次搜索尽快出结果；批量导入时界面不能假死，能取消 |
| 质量 | 解析和嵌入模块写单测；最终核心模块覆盖率接近 90% |
| 安全 | 数据只放本机应用目录；提供清除索引 |
| 开源 | 项目符合 Apache 2.0 开源标准 |

## 4.无障碍
- 搜索框、结果列表、按钮
- NVDA 或 VoiceOver 能读出按钮名称和结果标题
- 不只靠颜色区分「成功 / 失败」
- 设置里提供高对比和更大字号的选项
- 使用 Accessibility Scanner 或 WAVE 验证

## 5.技术栈
| 部分 | 选用 |
| :--- | :--- |
| 界面 | Flutter |
| 推理 | TensorFlow Lite |
| 模型 | BERT（文本）+ MobileCLIP（图像） |
| 文档解析 | PDFium + Apache Tika |
| 向量库 | Chroma DB |
| 测试 | Flutter Test；原生部分用 Google Test |
| 版本控制 | Git + GitHub |
| 无障碍验证 | Google Accessibility Scanner + WAVE |

## 6.MVP
- 选一个含PDF、DOCX、几张图片的文件夹，能完成索引
- 断网输入一句不含文件名的话，Top 结果里能出现目标文件
- 结果可以打开原文件
- 只用键盘能完成一次搜索

## 7.实验数据
- NQ：几段长文本，测文本检索
- COCO：几十张图，测图像检索
- RVL-CDIP：少量扫描件
- 测试文件混合文件夹：中英PDF + 截图 + DOCX
