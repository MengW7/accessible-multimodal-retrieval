The Apache Tika toolkit detects and extracts metadata and text from over a thousand different 

file types (such as PPT, XLS, and PDF). All of these file types can be parsed through a single 

interface, making Tika useful for search engine indexing, content analysis, translation, and 

much more. Tika identifies a file’s type from its bytes, so a missing or misleading extension 

does not change the result.
