# W06 D3 人工复测清单

截图、原生窗口和 Windows 权限设置由你操作。使用 [D2 人工清单](D2_人工验证清单.md) 的准备命令生成本次独立夹具和数据目录，并按 [D3 构建哈希](logs/D3_windows_build_sha256.txt) 核对当前的 `desktop.exe` 和 `data/app.so`。同一测试的两个窗口须使用同一 `AMR_DATA_DIR`。每项记录构建哈希、系统版本、实际结果、时间和证据文件。

- [ ] **D3-M01 双实例建库和清库。** 先在窗口 A 导入少量正常文件，然后打开同配置的窗口 B。让 A 对一批新文件建库。A 仍在运行时，在 B 分别尝试建库和确认清库，两次操作应显示“另一个实例正在修改此文件库”。等待 A 完成后在 B 重新建库，检查复用数量、目录记录及原有文档的检索结果。建议保存冲突提示和重试结果截图。
- [ ] **D3-M02 建库时关闭窗口。** 开始索引一批新文件，至少一份完成后用系统窗口关闭按钮退出。记录退出耗时和是否出现无响应。使用同一数据目录重启，确认已提交文档可搜索，重新索引能复用已提交文档并补齐剩余文件。建议保存关闭前进度、重启结果和续建计数截图。
- [ ] **D3-M03 数据目录写权限恢复。** 在另外的独立验证目录使用受限 Windows 账号或目录 ACL 构造写入被拒。启动或尝试索引，记录检查项、完整提示及实际权限配置。恢复该测试账号对该目录的写权限后重新检查或重启，完成建库并检索。记录源样本和已有索引是否仍可用。此项补实际 Windows ACL 证据。

可将证据保存到 `reports/week6/logs/` 或 `reports/week6/screenshots/`。D2 的真实文件打开和断网流程，以及 D5 的读屏与焦点复测，继续按各自清单记录。
