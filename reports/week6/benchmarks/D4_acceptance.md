# W06 D4 性能判据（优化前冻结）

2026-11-06。沿用 D1 的本机预算及固定查询“离线检索”。使用 Windows x64 生产原生 ONNX CPU 资源，以同一台机器的优化前生产探针为对照。Windows 桌面 UI 延迟另测。

- 98 块夹具：MiniLM / CLIP 文本 / CLIP 视觉热前向 p95 ≤60/30/45 ms，热管道 p95 ≤100 ms，97 个文本块 Top-5 扫描 p95 ≤1.5 ms，会话冷建库 p95 ≤11 s，采样进程树峰值 ≤1.35 GiB。
- 扩展到 1k / 5k / 10k 时，沿用 W4 10k 向量扫描 60 ms 作为参考门槛。D4 按 p95 检查，各档普通向量扫描 p95 ≤60 ms，热管道 p95 ≤200 ms，进程树峰值 ≤1.35 GiB。独立的全同分对照也报告相同扫描门槛。
- 冷态 5 轮、热态每个配置 30 个样本，最近秩法 p50 / p95。除 D1 夹具外，实库固定测全库和 a/ 前缀；固定 Top-5 端到端，向量扫描 Top-50（小夹具 Top-5）。库快照共用，模型、资源和查询顺序相同。内存单独标明工作集和 Dart RSS。
- 只有 Top-K 排名、分数、路径、页码、UTF-16 偏移、通道与片段一致，并且相同条件的复跑支持时才计入性能收益。推理若保持原实现，只判预算和回归。压测含坏文件、取消、增量、重新打开、清空及 SQLite 完整性核对。
