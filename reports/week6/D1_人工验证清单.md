# W06 D1 人工验证清单

自动基线、资源缺失诊断及对应证据见 [D1 阶段记录](W06_D1_checkpoint.md)。以下由项目开发者在目标机器操作并留证。当前各项待回填。

每项记录测试日期、提交或构建 SHA-256、操作系统和工具版本、实际结果、判定及证据路径。Windows 本机材料放在 `reports/week6/logs/` 或 `reports/week6/screenshots/`。日志与截图中使用仓库样本和独立索引目录。

## D1 必做准备与构建冒烟

- [ ] **M-01 Windows 候选构建。** 从仓库根目录打开 PowerShell，执行以下冒烟命令。它会启动候选程序的专用冒烟入口，工作目录为系统临时目录，结果写入指定目录，使用新夹具和新数据库。

  ```powershell
  $repo = (Get-Location).Path
  $exe = Join-Path $repo 'apps/desktop/build/windows/x64/runner/Release/desktop.exe'
  Get-FileHash -Algorithm SHA256 -LiteralPath $exe, (Join-Path (Split-Path $exe) 'data/app.so')
  & "$repo/apps/desktop/tool/verify_runtime.ps1" -Executable $exe -DevRoot $repo `
      -OutputDirectory "$repo/reports/week6/logs/D1_windows_executable"
  ```

  对照四种预期。development 退出 0，并记录 TXT、DOCX、PDF、PNG、文本与图像空间及 Top-5 出处。release_gap、missing_resources、missing_java 各退出 1，JSON 分别指出生产适配器、资源、Java 阻塞。保留脚本输出和 JSON。

- [ ] **M-02 收集平台证据。** 核对 Windows、macOS、Linux 的 CI 分别对应哪个提交，保存 run 链接、结果和构建日志。登记 macOS + VoiceOver 与 Linux 的可用设备、系统版本、操作人员和预计日期；暂缺设备时记为阻塞。
- [ ] **M-03 安排独立试用。** 由项目开发者邀请 2–3 名试用者，其中至少一人熟悉键盘或读屏。用 [W5 可用性脚本](../week5/UI可用性测试报告.md) 的 T1–T5。记录匿名编号、确认日期、拟用设备和辅助技术；正式用时、求助和结果在执行后填。

## 接续 D2 / D5 的人机操作

- [ ] **M-04 原生闭环。** 从仓库根目录在单独的 PowerShell 窗口准备数据并启动候选构建。

  ```powershell
  $repo = (Get-Location).Path
  $manual = Join-Path $env:TEMP ('amr-w06-manual-' + [guid]::NewGuid().ToString('N'))
  $fixtures = Join-Path $manual 'fixtures'
  New-Item -ItemType Directory -Path $fixtures -Force | Out-Null
  foreach ($name in 'sample.docx', 'sample.pdf', 'sample.png') {
      Copy-Item -LiteralPath "$repo/datasets/samples/$name" -Destination $fixtures
  }
  Set-Content -LiteralPath "$fixtures/smoke.txt" -Value '离线检索验证' -Encoding utf8
  $env:AMR_DEV_ROOT = $repo
  $env:AMR_DATA_DIR = Join-Path $manual 'data'
  $fixtures
  & "$repo/apps/desktop/build/windows/x64/runner/Release/desktop.exe"
  ```

  用原生选择器导入输出的夹具目录。搜索“离线检索”并筛选 PDF，核对页码和路径，在系统查看器打开，退出并从同一 PowerShell 窗口重启后重查。保存 `M04-index.png`、`M04-results.png`、`M04-viewer.png`，并记录成功的文件及查看器。
- [ ] **M-05 故障恢复。** 在同一个副本上测试缺失源文件、取消后续建、原样增量和清空确认。记录已提交数据、源文件哈希、提示文案与恢复步骤。原件与评测库留在其原有路径。
- [ ] **M-06 断网。** 先准备齐全本地资源，再由你隔离网络、确认隔离有效，执行导入、查询、打开和重启。记录时间、隔离方式、应用与子进程的 DNS/出站观察，单列系统查看器。
- [ ] **M-07 辅助技术与显示。** 按 [W5 人工验收矩阵](../week5/E_验收矩阵.md) 复测纯键盘和 NVDA，记录自动播报、焦点恢复、100%/150%/200% 字号及高对比。macOS 的 VoiceOver 使用同样脚本单独记录。截图用于显示与焦点证据，朗读内容另留文字或录音。
