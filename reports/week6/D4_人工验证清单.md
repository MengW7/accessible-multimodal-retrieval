# D4 人工验证清单：Windows 桌面压力与离线观察

本清单由项目开发者执行。使用 D5 候选或已记录哈希的 Windows release，结果注明实际构建、运行资源哈希、系统版本和时间。测试只使用本地合成语料及单独的应用数据目录。不要把真实个人资料放进证据目录。所有截图、桌面交互和系统网络操作均由你完成。

| 编号 | 步骤 | 判据及需回填的证据 |
|---|---|---|
| D4-M01 桌面热查 | 取下文 10k 夹具。从仓库外启动 release，选择夹具建库。先预热，再对“离线检索”做 30 次查询。全库与 TXT 筛选分两轮。用录屏时间轴或外部计时记录提交到可选择结果的时间。 | 记录逐次时间、p50/p95、筛选、Top-5 和出处。自动探针的筛选为 a/ 路径前缀，桌面 TXT 结果单列。截图保留可操作结果、通道和出处。若能读取任务管理器的工作集，单列应用与 Java 的峰值及采样频率。 |
| D4-M02 长任务 | 新数据目录，从空库导入约 10k 块。等进度进入写入阶段后按取消并计时。检查已有结果，退出并重启，重新选目录续建。再编辑夹具副本中一个 TXT、重建、清空。 | 回填导入耗时、取消到界面安全状态、取消前后计数、续建复用和改动文件重建、坏 DOCX 提示。清空后应用无结果，源文件仍在。截图保留取消、续建及错误提示。 |
| D4-M03 出站观察 | 用可按进程关联的捕获工具（如本机已有的 Sysmon，核实已启用 Event ID 3 和 22）记录 UTC 起止及应用和子进程 PID。先做无敏感信息的可见性对照，再隔离外网并确认隔离有效。隔离期间冷启动、导入混合夹具、查找、打开本地文件、退出重启、清空、再次退出。网络复测可单用小夹具 `.dart_tool/w06-d4/corpus/tiny`，便于覆盖 Java/Tika、文本和图像而不等大库建完。 | 回填隔离范围、工具及规则、可见性对照、DNS 事件、TCP/UDP 或阻止事件、外部查看器进程与行为。确认覆盖 Dart/Flutter 内原生 ONNX 和 Java/Tika。事件截取按时间和 PID 过滤；不要把 DNS 缓存或空 TCP 表当成无外发证明。 |
| D4-M04 本地残留 | 运行前后分别对夹具树取相对路径+SHA-256；测试过程中若主动编辑夹具，先恢复原始内容再取最终哈希。记录独立 AMR_DATA_DIR 与测试用临时目录的文件名、大小。退出后确认应用及本次 Java 子进程已退出。 | 两份源文件哈希一致；列出索引、WAL/SHM、目录/显示设置与临时残留；对导出的日志检查绝对路径、查询和片段并脱敏。清空只按逻辑清空验收。 |

如使用本次自动压测的夹具，从仓库内 `.dart_tool/w06-d4/corpus/fixtures` 复制一份到新的本地目录。包含 9,902 个短 TXT、固定的 TXT/DOCX/PDF/PNG 和故意损坏的 DOCX。不要直接在基准夹具原件上做桌面测试。发布运行资源与隔离数据目录的启动方式见 [D2 人工清单](D2_人工验证清单.md)。

每条回填：状态、实际日期/时区、构建 SHA-256、资源版本、数据目录、夹具哈希、实际操作与结果、截图/日志路径、尚未覆盖的范围。macOS 与 Linux 的原生生产运行及 DNS/出站证据另行记录。
