## 4. 界面与接口设计任务

| 功能区 | 最小功能 | 状态与交互要求 |
|---|---|---|
| 文件库 | 添加目录、查看索引状态、重建、取消、清除索引 | 显示处理中/完成/部分失败；防重复提交；破坏性索引操作需确认并说明源文件保留 |
| 搜索 | 查询输入、提交、类型/路径/修改时间筛选、清除筛选 | 空查询提示；加载态；连续查询只呈现当前请求；错误后可重试 |
| 结果 | 文件名、类型、路径、文本片段、可用页码、打开原文件 | 缺失文件和系统打开失败分别提示；图片有替代文本；排名分数不显示为正确概率 |
| 设置 | 高对比、跟随系统/应用字号、快捷键说明、索引位置 | 设置可持久化和恢复默认；屏幕缩放与应用字号不重复放大 |

接口与数据约定：

- Flutter 组合根负责装配服务、管理生命周期；Widget 不直接操作 SQLite 或启动探针脚本。
- 文件扫描、解析与向量化必须保持界面可响应。先测实际卡顿；需要后台执行时定义进度、取消和错误消息，不只给同步重任务套一个 `Future`。
- 使用结果携带的真实路径、页码和偏移。文本偏移沿用 UTF-16 code unit；不能将扩展片段的起点当作命中块起点。
- MVP 可展示出处并打开原文件。系统查看器不支持指定页/段时，明确说明定位限制；应用内精确高亮仅在坐标映射验证后启用。
- 如果生产嵌入运行时尚未接通，可用替身推进 Widget 测试，但替身结果不能作为真数据闭环通过的证据。开发运行时演示应标明依赖与发布缺口。

## 5. 无障碍实现与验证

以 PDF 指定的 WCAG 2.1 AA 为目标建立检查映射，报告已检查的准则、范围和缺口，不把工具零告警等同于完整合规。

### 5.1 必做能力

| 能力 | 实现任务 | 人工验收 |
|---|---|---|
| 读屏 | 为按钮、输入框、筛选、结果和图片补齐名称/角色/状态；合并重复朗读；让加载、完成、错误可被感知 | NVDA 从导入到打开结果全程可操作；保留操作步骤及实际朗读内容；VoiceOver 单列验证 |
| 纯键盘 | 合理 Tab/Shift+Tab 顺序、可见焦点、Enter/Space 激活、Esc 退出弹窗；弹窗关闭后恢复焦点 | 不用鼠标完成全部主流程；没有键盘陷阱；快捷键不覆盖常用输入操作 |
| 高对比 | 所有主要界面和状态共享主题；文字、图标、焦点及禁用态逐项检查；错误不只靠颜色 | 明暗/高对比主题下关键内容可辨；记录测量颜色和对比结果 |
| 动态字号 | 尊重系统缩放；长路径换行或提供可访问的完整文本；按钮和弹窗适应大字号 | 在 100%、150%、200% 文字缩放下检查，无文字遮挡导致的功能丢失；窄窗口可滚动到全部操作 |

拟定快捷键：`Ctrl+L` 聚焦搜索、`Enter` 提交、`Esc` 关闭当前弹窗。macOS 使用平台对应修饰键。最终按实测冲突调整，并保持指南与界面一致。

### 5.2 工具适用范围

- Windows 原生 Flutter：使用 NVDA、键盘走查、Flutter 语义测试及对比度检查，保留版本与截图/录像证据。
- macOS 原生 Flutter：使用 VoiceOver 重复同一脚本；没有 macOS 环境时登记环境阻塞及 W6 补测任务。
- Accessibility Scanner 面向 Android；若没有 Android 测试目标，在报告中列为“当前桌面范围不适用”，保留与 PDF 指定工具要求的差异。[官方使用介绍](https://www.youtube.com/watch?v=Yxy4p-eDEpw)
- WAVE 面向网页。只在确有可检查的 Web 页面时使用，并注明该结果不代表原生桌面 UI；不为得到一张扫描报告临时扩展 Web 产品范围。[WAVE 官方说明](https://wave.webaim.org/)
- 报告必须保留 PDF 指定工具的对应行，说明替代验证方法与未覆盖范围。替代方法不自动消除与原任务要求的差异。

| 工具与平台不匹配 | Scanner/WAVE 无法覆盖桌面原生 UI | 记录不适用原因及替代证据 | 保留任务要求差异，不宣称完整合规 |
