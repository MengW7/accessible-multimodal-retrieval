## 拍摄前准备

以下步骤使用新建的专用演示目录，不操作真实工作资料或评测库。

1. 新建输入目录，例如 `<repo>/tmp/manual-screenshots/fixtures`，在其中新建 `notes` 子目录。
2. 在输入目录保存 `good.txt`，内容可写：`离线检索在本地建立索引，支持按文件类型筛选。`
3. 在 Word 中写入一段介绍离线检索的文字，使用"导出为 PDF"保存到 `notes/sample.pdf`。必须是真实可打开的 PDF，不能只修改扩展名。
4. 另存一份普通文本为 `bad.docx`，仅作为故意损坏的测试文件。确认最终文件名不是 `bad.docx.txt`，不要覆盖正常 Word 文件。
5. 为这次演示使用新的应用数据目录。在仓库根目录 PowerShell 中执行：

```powershell
$env:AMR_DEV_ROOT = (Get-Location).Path
$env:AMR_DATA_DIR = Join-Path $env:AMR_DEV_ROOT ('tmp/manual-screenshots/data-' + [guid]::NewGuid().ToString('N'))
& './apps/desktop/build/windows/x64/runner/Release/desktop.exe'
```

6. 先保持窗口大小不变，选择"设置"→"明暗主题：浅色"，关闭"高对比模式"，将"文字大小"设为 100%。前五张图使用这套基础显示配置。
7. 每次截取前，将鼠标移到目标窗口外，等悬停提示消失；使用系统截图工具的窗口模式保存 PNG。用"隐藏鼠标指针/不捕获光标"选项（若工具提供），保存后检查图内没有指针和鼠标高亮。不要通过点击窗口外来移走键盘焦点。

## 11 张截图的具体操作

### 图 01：文件导入结果

**截图名称（文档图题）：** 文件导入结果与损坏文件错误提示。

**放入：** UI 可用性测试报告；文件名 `01-library-import.png`。

1. 进入"文件库"，点击"选择目录"。
2. 选择准备好的 `fixtures` 根目录并确认，检查"目录的绝对路径"已正确填入。
3. 点击"建立 / 增量更新索引"，等待任务结束。
4. 查看"本次文件状态"，确认 `good.txt`、`sample.pdf` 建库成功，`bad.docx` 显示失败及原因；必要时滚动，让汇总与成功/失败条目同时可见。
5. 移开鼠标并截图。

**画面应包含：** 文件库标题、完成汇总、至少一条成功记录、损坏文件的失败原因。使用上述三文件新库时，通常为新写入 2、失败 1；记录实际结果，不手动改数字。

### 图 02：增量更新结果

**截图名称（文档图题）：** 增量更新与未修改文件复用结果。

**放入：** UI 可用性测试报告；文件名 `02-library-incremental.png`。

1. 接着图 01 操作，不修改、不移动输入文件，也不更换应用数据目录。
2. 在相同目录再次点击"建立 / 增量更新索引"。
3. 等待结束，检查两个正常文件显示"已复用"，文档数量没有重复增加。
4. 将汇总和"已复用"的条目滚动到同一画面，移开鼠标后截图。

**画面应包含：** 复用数量、"已复用"的文件记录和当前索引数量。故意损坏的 `bad.docx` 可能再次失败，这是同一测试输入的预期表现。

### 图 03：检索结果与出处

**截图名称（文档图题）：** 本地检索结果及来源信息。

**放入：** UI 可用性测试报告；文件名 `03-search-results.png`。

1. 进入"搜索"，点击"清除筛选"。
2. 在"搜索本地内容"输入样本文字中的关键词，例如 `离线检索`。
3. 确认文件类型为"所有类型"，相对路径、修改日期均为空。
4. 点击"开始搜索"或在查询输入框按 Enter，等待进入"结果"页。
5. 滚动到有完整结果卡片的位置；优先让 PDF 结果的文件名、片段、来源路径、页码和"打开原文件"按钮可见，再截图。

**画面应包含：** 本次查询、应用条件和完整出处信息。TXT 没有物理页码时保留其真实说明，不添加页码；若 PDF 结果位于后面，可滚动展示。

### 图 04：筛选后的检索结果

**截图名称（文档图题）：** PDF 类型筛选后的检索结果。

**放入：** UI 可用性测试报告；文件名 `04-search-filter-pdf.png`。

1. 从结果页点击"修改搜索条件"，或进入"搜索"。
2. 保留与图 03 相同的查询文本，点击"清除筛选"。
3. 在"文件类型"下拉框选择"PDF"，其余筛选留空。
4. 再次点击"开始搜索"。只改变表单不提交，不会更新结果。
5. 等待结果出来，检查本次条件显示 PDF，结果来源为 `sample.pdf`，然后截图。

**画面应包含：** 已应用的 PDF 条件、PDF 文件名、片段、相对路径和实际页码。

### 图 05：无效日期提示

**截图名称（文档图题）：** 无效日期输入的校验提示。

**放入：** UI 可用性测试报告；文件名 `05-invalid-date.png`。

1. 返回"搜索"，点击"清除筛选"，保留非空查询文本。
2. 在"修改时间晚于日期"中输入 `2026-02-30`，检查使用英文连字符。
3. 点击"开始搜索"。
4. 确认表单显示日期不存在或检查年月日的提示，保留错误输入及提示文字，移开鼠标后截图。
5. 拍完后点击"清除筛选"，重新提交一次正常查询，确认可以继续使用。

**画面应包含：** 无效日期输入、明确的文字错误原因及可继续操作的按钮。不要把这张图写成"没有检索结果"。

### 图 06：确认弹窗与键盘焦点

**截图名称（文档图题）：** 清除索引确认弹窗与默认键盘焦点。

**放入：** 无障碍合规验证报告；文件名 `06-dialog-keyboard-focus.png`。

1. 在专用演示库进入"文件库"，等待当前任务结束。
2. 将鼠标移到目标窗口外；通过 Tab 移动焦点，直到"清除全部索引"按钮出现焦点框。按过头时用 Shift+Tab 返回。
3. 按 Enter 打开确认弹窗。此步骤只打开弹窗，不确认清除。
4. 检查默认焦点位于"保留索引"，弹窗有索引位置、清除范围及"源文件保留"的说明。
5. 保持键盘焦点，使用不会改变焦点的截图方式保存；若唤起截图工具后焦点框消失，取消截图、返回应用并重新用键盘聚焦后再拍。
6. 拍完按 Esc 关闭弹窗，确认索引仍在。

**画面应包含：** 完整弹窗、两个操作按钮和"保留索引"的可见焦点框。不要点击"确认清除索引"。

## 使用方式

- 正文围绕实际功能或验证结论引用对应截图，并写清操作条件与图中结果。
- 周报引用上述报告即可，不必重复贴图；用户指南按具体操作说明需要选图。
- 进度、取消恢复、清空和重启等其他截图可作为附件，支持对应测试结论。
- 截图不能代替读屏实测、独立用户测试或断网测试，也不能据此直接宣称完整无障碍合规。

## 截图要求

- 将鼠标移到目标窗口外，等待悬停提示消失后再截；需要展示的键盘焦点框保留。
- 使用原始分辨率的无损 PNG，不放大低清截图；保存后以 100% 比例检查文字。
- 字号对比保持同一页面、同一窗口尺寸及主题，避免其他变量干扰比较。
- 本文件规定选图内容与操作条件；是否满足对应图题，以"当前画面"列的核对结果为准。
