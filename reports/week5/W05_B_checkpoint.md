## 2. 实现说明

- `LibraryService` 定义 `load/index/cancel/clear/close`，`LibraryProgress`、`LibraryRun`、
  `LibraryFile`、`LibrarySnapshot` 作为可跨 isolate 发送的状态对象。
- `WorkerLibraryService` 管理常驻 isolate 的握手、请求/响应、进度、错误及关闭。
  `RuntimeSession` 和 SQLite 句柄留在 worker 内，不传给 Widget。
- `RuntimeSession` 增加入库进度与解析报告回调；解析失败不会因为被核心 `indexable`
  过滤而从 UI 中消失。
- 核心 `IndexProgress` 增加可选 `path/outcome/errorMessage` 及 `written/reused/failed`
  累计计数；保留原有方法签名和既有调用兼容性。每份文件后让出一次事件循环，
  避免纯 SQLite 快速复用一直占用微任务而收不到取消端口消息。
- 原有切块、嵌入、检索打分和调参范围未扩展。单文件写入仍由核心存储事务保证，
  未嵌完的文件不会覆盖已提交版本。
- `LibraryPage` 增加路径输入、目录选择、任务进度、取消、状态分页、目录历史与增量按钮。
  清除入口包含明确确认，后台只清除应用自己的索引与目录记录。
- Windows 正常关闭增加异步生命周期握手：先请求控制器取消/关闭 worker，再关闭窗口。
  不以直接结束 worker isolate 代替正常释放嵌入进程。该原生关闭动作留待用户实机复核。
