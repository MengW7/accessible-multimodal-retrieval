# 覆盖率报告

## 命令

每个包在自己的目录里执行。带 `integration` 标签的测试会读 `tokenizer.json`、fp32 ONNX 或数据集，这次排除在外。

```powershell
dart test --coverage=coverage --exclude-tags integration
dart run coverage:format_coverage --lcov --in=coverage --out=coverage\lcov.info --report-on=lib --package=.
```

`lcov.info` 复制到 `week4/coverage/<包名>.lcov.info`。包内的 `coverage/` 仍由 gitignore 忽略。

## 行覆盖率

统计的是各份 lcov 里 `LH` / `LF` 之和。百分数保留两位。

| 包 | 行命中 | 套件 | 门槛 | 判定 |
|---|---|---|---|---|
| `core_storage` | 488/573 = 85.17% | `00:02 +14` | ≥ 85% | 通过 |
| `core_retrieval` | 158/164 = 96.34% | `00:02 +8` | ≥ 85% | 通过 |
| `core_pipeline` | 280/298 = 93.96% | `00:03 +23` | ≥ 85% | 通过 |
| `core_parsing` | 979/1091 = 89.73% | `00:07 +98` | 不低于 80% | 通过 |
| `core_embedding` | 1250/1458 = 85.73% | `00:09 +93` | 不低于 85% | 通过 |

`core_embedding` 与第 3 周的 1250/1458 = 85.73% 相同。`core_parsing` 第 2 周快照是 949/1043 = 90.99%，当时插桩行数是 1043。这次库的插桩行数是 1091，行命中率 89.73%，仍高于 80%。

`core_pipeline` 里 `PythonEmbedServerHost.open` 会拉起本机 Python，默认套件没有走这条路径。其余库文件的未命中行不把总覆盖率拉到 85% 以下。
