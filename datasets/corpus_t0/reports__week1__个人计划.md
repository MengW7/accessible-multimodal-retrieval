## 2.每周交付

**W1** ｜09/24｜16h｜需求冻结、环境搭建
- 任务理解 + 个人 8 周计划
- 需求分析：离线、跨平台、WCAG 2.1 AA、支持 TXT/PDF/DOCX/JPG/PNG
- 环境搭建验证：Flutter SDK、TFLite、Git、Chroma等
- 验证集下载计划（NQ / COCO / RVL-CDIP / Wiki 验证集）
- 风险清单：模型体积、CPU 推理延迟、PDF 解析、假期工期

**W2**｜09/30｜16h｜系统架构 + 文件解析模块方案
- 六层架构图：File I/O / Parsing / Embedding / Vector DB / Retrieval / UI&无障碍
- TDD 草稿（模块边界、接口、数据流）
- 解析模块设计：TXT/PDF/DOCX/JPG/PNG + 元数据字段
- 文件解析模块 + 单测（目标后续 ≥80%）

**W3**｜10/10｜24h｜多模态 Embedding 引擎 + MVP
- BERT → TFLite 文本向量可跑通
- MobileCLIP 图像向量可跑通
- 统一 Embedding 接口（文本/图像同一调用方式）
- 用 NQ / COCO 小验证集
- 最小 Demo：选 1 个文件夹 → 解析 → 向量化 → 打出 embedding（尚可不接完整检索 UI）

**W4**｜10/16｜40h｜向量库 + 核心检索，打通 MVP
- 本地 Chroma：写入、索引、相似度查询
- 混合检索：关键词 + 向量打分 + 排序 + 过滤
- 全链路 MVP：摄入 → 解析 → embedding → 存储 → 搜索 → 返回
- 端到端功能测试报告
- 检索准确率基准

**W5**｜10/23｜40h｜跨平台 UI + 无障碍
- 四个核心界面：文件库 / 搜索 / 结果 / 设置
- 无障碍：读屏（NVDA/VoiceOver）、纯键盘、高对比、动态字号
- Accessibility Scanner + WAVE 扫描记录
- 可用性测试记录
- 无障碍用户指南草稿

**W6**｜10/30｜40h｜全链路联调、测试、性能
- 全模块集成的稳定构建
- 单测 / 集成 / E2E / 压测；核心模块单测目标 ≥90%
- 性能优化报告：推理延迟、检索耗时、内存
- P0/P1 缺陷清零清单修复
- 离线安全自查：无云上传、无泄露

**W7**｜11/06｜40h｜文档、开源合规、体验打磨
- 技术文档：架构深潜、API、维护手册
- 用户手册：安装、功能、无障碍操作
- 开源合规：依赖许可证核对 + Apache 2.0
- UI 打磨与残留 bug 修复
- Demo 脚本

**W8**｜11/13｜40h｜终版构建、Demo、作品集打包
- Windows / macOS / Linux 可运行包
- GitHub 公开仓库：README、License、贡献指南
- 5 分钟 Demo 视频
- 实习作品集打包（代码 + 文档 + 测试报告 + 视频）
- 对照项目「Full Deliverables List」的最终勾选表
