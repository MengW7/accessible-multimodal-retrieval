## 1.任务拆解
### W1 需求定义与环境搭建
- 读工程规范 / WCAG / 开源规则 
- 编写功能与非功能需求 
- 安装 Flutter、TFLite、Git、Chroma、解析依赖 
    - 验证整条工具链在本机可编译、可跑，交付物为环境验证记录
- 拉取 NQ / COCO / RVL-CDIP / Wiki 的验证子集 
    - NQ 测长文本检索，COCO 测图文 embedding，RVL-CDIP 测扫描件/文档图，Wiki 测批处理与长文档。只拉验证子集，控制体积
- 编写风险清单
    - 提前标出最可能让 8 周失败的点：模型转换失败、CPU 推理太慢、PDF 解析丢文本图像、无障碍漏项、许可证冲突等

### W2 系统架构设计
- 设计系统架构并绘制 6 层架构图
- 实现并测试解析模块（5 种格式）
- 实现批量入库与元数据提取
    - 需要目录扫描、跳过损坏文件、记录失败原因、提取文件名/大小/修改时间/格式等元数据，为后续过滤和结果展示做准备。
- 编写 完整技术设计文档（TDD）

### W3 多模态嵌入引擎
- 集成BERT 
    - 离线推理和输入预处理
- 集成TFLite；MobileCLIP 端侧化；统一 embedding 接口；NQ / COCO 验证；批量 embedding

### W4 向量数据库集成与核心检索逻辑实现
- 集成Chroma
    - Chroma 是本地向量索引和相似度查询层。
- 混合打分/排序/过滤 
    - 混合检索把纯向量和纯关键词分数融合后排序，并支持按格式、时间、路径过滤
- 构建检索流水线
    - 一条完整路径：文件 → 解析 → embedding → 入库 → 查询 → 排序返回
- 端到端功能测试 
- 检索准确率基准
    - 用自建小测试集记录 Top-K 是否命中预期文件，形成可对比数字

### W5 跨平台 UI 开发与无障碍功能实现
- Flutter 四个核心界面主界面 
    - 文件库、搜索、结果、设置，同一套 UI 在多个平台可用
- 无障碍功能：NVDA/VoiceOver、键盘、高对比、字体缩放
- Scanner / WAVE 
- 可用性测试
    - 真实操作找出设计问题，记录任务完成情况和改进

### W6 系统集成、全面测试与性能优化
- 全模块集成：解析、嵌入、检索、UI
- 单测/集成/端到端/压力测 
    - 单测确保模块功能正确，集成测确保接口契约，E2E 确保用户路径，压力测保大批量文件时还能用
- 性能优化
    - 优化任务耗时和系统资源占用
- 修复缺陷 
    - 只修复严重的缺陷
- 离线数据安全审查
    - 没有文件上传云端

### W7 文档编写、开源合规与最终打磨
- 架构/API/维护手册 
- 用户手册（含无障碍操作）
    - 能让使用者快速知晓软件如何使用
- 许可证审查（Apache 2.0）
    - 查看各个模块依赖是否和开源许可兼容
- UI 打磨 
- 项目演示脚本

### W8 最终交付、演示与作品集打包
- Win / macOS / Linux 可执行文件 
    - 为每个平台各构建一份产品，并写出运行前置条件
- GitHub
    - README + License + Contributing
- 5 分钟 Demo 视频 
- 打包
